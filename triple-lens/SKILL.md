# Triple Lens — 三层透镜分析法

对任何分析对象（公司、概念、技术、领域、人物），从三个互相独立的维度切开，交汇处即本质。

**三个维度**：
1. **纵向钻探**（→ 不可再分的本质）
2. **生成器分解**（→ 最少独立元素）
3. **秩序判断**（→ 创造秩序还是消耗秩序）

## 何时使用

- "分析一下这个公司/概念/技术"
- "XX 的本质是什么"
- "拆解一下这个领域"
- 投资前的商业模式深度理解（与 `investment-stress-test` 互补——stress-test 问"会不会死"，triple-lens 问"是什么"）
- 芯片设计决策（"这个架构方案的本质是什么"）
- 学习新领域的第一步

---

## 第一层：纵向钻探（→ 不可再分的本质）

从表面现象出发，层层剥开，直到抵达不能再分的第一因。

### 方法

```
表面 → 它看起来是什么？
  ↓
功能 → 它做了什么？
  ↓
机制 → 它为什么能做到？
  ↓
前提 → 为什么是这个前提而不是别的？
  ↓
本质 → 抽掉这一层，整个东西就不成立了
```

### 输出

一句本质陈述（不超过 50 字）+ 每层一句话的钻探路径。

---

## 第二层：生成器分解（→ 最少独立元素）

就像线性代数里的基向量——所有其他特征都可以由这几个生成器组合出来。

### 方法

1. 列出所有显著特征/能力/属性
2. 逐对检查：A 能从 B 推导吗？B 能从 A 推导吗？
3. 逐步消除可被组合出来的元素
4. 剩下 3-7 个不可再少的独立生成器

### 判定标准

- **独立性**：每个生成器不能由其他生成器组合而成
- **完备性**：所有显著特征都能由生成器组合解释
- **最小性**：不能再少一个

### 输出

生成器清单，每个带验证："如果把 X 拿掉，哪些现象无法解释？"

---

## 第三层：秩序判断（→ 秩序创造机器）

这个东西存在之后，它所在的系统是变得更有序了，还是更混乱了？

### 分析维度

| 维度 | 秩序创造 | 秩序消耗 |
|------|---------|---------|
| **对用户** | 降低认知/决策成本 | 增加选择负担，制造焦虑 |
| **对行业** | 建立标准，降低交易成本 | 制造信息不对称 |
| **对时间** | 积累复利（越用越好） | 边际效益递减 |
| **对自身** | 护城河随时间增长 | 护城河在消失 |

### 判断公式

```
秩序净值 = 创造的秩序 − 消耗的秩序 − 维持自身所需秩序
```

> 0 且持续增长 → 秩序创造机器。≈ 0 → 平庸。< 0 → 秩序寄生虫。

---

## 综合交汇

三层透镜在交汇处整合：

- **本质 × 生成器**：这个本质是通过哪些生成器实现的？
- **本质 × 秩序**：这个本质本身是创造还是消耗秩序？
- **生成器 × 秩序**：哪些生成器在创造秩序，哪些在消耗？

### 最终输出格式

```
## Triple Lens 分析报告

**对象**：XXX

### 第一层：本质
[≤50字]

钻探路径：表面→功能→机制→前提→本质

### 第二层：生成器
[3-7个独立生成器+验证]

### 第三层：秩序判断
四维表格 + 秩序净值判断

### 交汇
[本质 × 生成器 × 秩序]

### 一句话
[≤30字终极判断]
```

## 与 investment-stress-test 的关系

| | triple-lens | investment-stress-test |
|------|-------------|----------------------|
| **问什么** | 这个东西是什么 | 这个投资会不会死 |
| **时机** | 第一次接触 | 准备买入前 |
| **互补** | stress-test 第0号规则（技术≠商业）需要 triple-lens 的秩序判断支撑 |

建议顺序：先 triple-lens 理解本质 → 再 stress-test 做买入决策。

---

## 铁律

1. 三层必须独立——不能用同一套事实回答三层
2. 本质不超过 50 字——超过说明还没钻到底
3. 生成器不超过 7 个——超过有冗余
4. 秩序判断要诚实——赚钱 ≠ 创造秩序
5. 某一层不适用时，诚实说明，不强套
